---------------------------------------------------------
7. CONCLUSION
---------------------------------------------------------

Git and DVC together provide a reproducible machine
learning workflow.

Git manages source code, configuration and experiment
history, while DVC manages large datasets and model
artifacts.

The use of params.yaml and dvc.yaml allows the complete
ML experiment to be reproduced using dvc repro.

The hyperparameters for Random Forest V1 (100 trees,
depth 5) and V2 (200 trees, depth 10) are versioned in
params.yaml. Both versions achieve perfect metrics on
this dataset (accuracy = precision = recall = F1 = 1.0),
verified via dvc metrics show and dvc metrics diff.
